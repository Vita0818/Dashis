# Dashis UI 样式审查报告

## 审查结论与建议 (UI Review Findings)

通过审查 `App/macOS/DashisDesign.swift` 与 `App/macOS/DashisDashboardComponents.swift`，当前 UI 整体采用了 macOS 原生风格、毛玻璃效果 (Glassmorphism) 且支持深色模式。但在细节层面存在一些可优化的空间，以达到更“高级 (Premium)”和专业的视觉体验：

1. **字体选择 (Typography) 偏离了 Dashboard 惯例**
   - 当前在 `DashisType` 中，`brand`、`title`、`body`、`caption`、`mono` 全部使用了 `.serif`（衬线字体）。
   - **调整建议**：对于数据密集的 Dashboard 而言，大量使用衬线字体会降低可读性，这在图表和数据看板中十分罕见。建议保留 `brand` 和大标题 `title` 使用 `.serif` 以建立独特的品牌感（Editorial look），而将 `body` 和 `caption` 改回现代无衬线字体（如 `.system` 或 `.rounded`），并将 `mono` 修改为真正的等宽字体 `.monospaced` 以确保数据对齐。

2. **配色方案 (Color Palette) 过于基础**
   - 当前状态色直接使用了默认的系统色 (`.systemBlue`, `.systemGreen`, `.systemOrange`, `.systemRed`)。
   - **调整建议**：这种做法相对安全，但这容易让应用看起来比较“普通”。为打造高端质感，建议自定义一套带有统一色调倾向的颜色池（例如：将默认蓝替换为高饱和度的深邃紫罗兰色/Indigo，将默认绿替换为更加柔和的薄荷绿或翠绿等），这能大幅提升视觉的定制感。

3. **暗色模式背景 (Surfaces) 缺少色相偏移**
   - `surface` 和 `mutedSurface` 纯粹使用了不同灰度的黑白色值（如 `Color(red: 0.06, green: 0.06, blue: 0.065)`）。
   - **调整建议**：现代高端 UI 通常会在暗黑模式的背景灰中混入极少量的品牌主色调（例如极其微弱的蓝紫色），这不仅能消除纯灰色的沉闷，还能让整体色调显得更深邃、有层次。

4. **卡片内边距与阴影细节 (Density & Shadow)**
   - `DashisGlassCardModifier` 使用了阴影 `y: 10, radius: 18`。
   - **调整建议**：这种投影参数在亮色模式下可能稍显厚重。如果是毛玻璃效果，建议进一步弱化阴影的不透明度，或是利用内阴影（Inner Shadow）强化边缘的高光感，以打造真正的“晶态”材质感。同时，考虑到未来可能接入更多的 Provider，可以对 `DashisProviderCard` 内部数据面板 (`stats`) 考虑引入紧凑模式，稍微收缩 `padding`。
