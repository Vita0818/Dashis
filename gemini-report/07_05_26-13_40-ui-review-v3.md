## 为什么现在的“玻璃+衬线”看起来糟心？

1. **“假玻璃”问题（没有底层光学变化）**：
   - 当前的 `.app-shell` 和 `body` 背景是死板的纯白（`#ffffff`）或纯黑（`#000000`）。在纯色背景上使用 `backdrop-filter: blur(20px)` 是**完全没有视觉效果的**（因为没有东西可供模糊）。这只会让面板的半透明颜色（如 `rgba(255, 255, 255, 0.76)`）叠加在纯白上，最终看起来只是一个发灰的实色块，毫无“玻璃”的清透感。
2. **缺乏玻璃的高光与边缘细节**：
   - 真实的毛玻璃不仅有模糊，还会有边缘的环境光反射。目前代码只是简单的 `border: 1px solid var(--border)`，缺乏高级感。
3. **衬线体（Serif）的排版不够极致**：
   - 衬线体自带优雅、复古的属性，但当前的排版字号和粗细对比不够强烈。小字号的衬线体会显得拥挤和老气，必须拉开 Typography 的尺度对比（例如标题极大且细，正文信息则搭配干净的无衬线体）。
4. **空间极度压缩**：
   - 玻璃态设计极其依赖**呼吸感（Whitespace）**。目前 `10px` 的网格间距让一堆玻璃卡片挤在一起，完全丧失了轻盈感。

## 让 Codex 拯救 UI 的建议方向

为了在**不违反项目禁止使用彩色主题（严守黑白基调）**的前提下，把“玻璃 + 衬线”做到顶级质感，您可以把以下要求转述给 Codex：

> “Codex，既然我要求了玻璃态和衬线体，我们需要把它做到顶级质感。请基于目前的黑白系统色约束进行以下修改：
> 
> 1. **激活真实的玻璃质感**：在纯白/纯黑背景下，`blur` 是没用的。请给 `html` 或 `body` 加一个非常克制的、纯灰度/黑白的**微妙网格背景 (Grid Pattern)**，或者使用纯黑白的柔和 Mesh Gradient（利用径向渐变），让底图有细微的明暗变化，这样上层的 `backdrop-filter: blur(20px)` 才能透出真正的毛玻璃折射感。
> 2. **强化玻璃边缘高光**：给 `.panel` 和 `.metric-card` 的 border 增加上边缘的半透明高光（例如 `border-top: 1px solid rgba(255, 255, 255, 0.4)`），并加入轻微的 `box-shadow`。
> 3. **衬线体的杂志化排版**：放大 `h1`, `h2` 等使用 `Georgia` 衬线体的字号，适当减小 font-weight（如调为 `400` 或 `500` 以突显字体的优雅感），并在数字（如 Metric 卡片中的大字数据）上强制使用无衬线体（Mono 或 SF Pro）以确保数据易读性。
> 4. **增加呼吸感**：将所有 grid 的 `gap` 统一拉大到 `20px` 或 `24px`，卡片内 padding 增加到 `20px`。
> 5. **恢复之前删掉的元素**：把被你删掉的 Sidebar logo、底部状态、Timeline 以及 Accounts 全部加回来，应用新的质感规则。”
